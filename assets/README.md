# README artwork

`zergraph-hero.png` is a 2172 × 724 pixel banner generated with OpenAI ImageGen.
It pays homage to the organic sprites and isometric terrain of StarCraft's original
Zerg art. It uses newly generated artwork rather than extracted game assets.
Zergraph is not affiliated with Blizzard Entertainment.

The three colonies represent software agents, field robots, and servers. Each keeps
a local graph. Glowing packets between them represent incremental updates. The scene
illustrates possible uses; it is not a deployment result or a protocol diagram.

The artwork stays in the repository and is excluded from the Cargo package.
